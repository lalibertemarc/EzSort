# EzSort

One click to sort your bags and bank in WoW Forever, in either direction.

## Features

- **Sort button**: a bag icon sits next to your open bags.
  - Left-click sorts your bags.
  - Shift-click sorts your bank (bank must be open).
  - Right-click flips the sort direction. The tooltip shows the current direction.
- **Key bindings**: sort bags, sort bank and flip direction under Options > Keybindings > AddOns > EzSort.
- **Loot direction**: choose whether new items fill your backpack or your leftmost bag first.

Sorting uses the game's own sort, so it respects the per-bag "ignore cleanup" settings.

## Install

Install from CurseForge or Wago, or download the zip from the [Releases](../../releases) page and extract the `EzSort` folder into:

```
World of Warcraft\_classic_beta_\Interface\AddOns\
```

## Commands

Use `/ezs` or `/ezsort`.

| Command | Does |
| --- | --- |
| `/ezs` | Sort bags |
| `/ezs bank` | Sort bank (bank must be open) |
| `/ezs reverse` | Flip sort direction |
| `/ezs loot` | Flip where new items go |
| `/ezs button` | Show or hide the sort button |
| `/ezs help` | List commands |
